# HOI4 戦略地域の航空優勢％・制空値・閣僚補正の実装解析

> 対象：今回の `hoi4.exe`（Ghidraプロジェクト `project/hoi4`）および innovative balance v13.00。  
> 内部固定小数点は `100000 = 1.0 = 100%` として通常の小数へ直して表記する。

## 1. 結論

戦略地域に表示される自軍の航空優勢％は、両陣営の有効制空値をそれぞれ `A`、`E` とすると、次の式である。

```text
AirSuperiorityPercent = A / (A + E) × 100
```

敵側は、両軍の合計が正なら次の値になる。

```text
EnemyPercent = E / (A + E) × 100
             = 100 - AirSuperiorityPercent
```

これは差分 `A - E` の線形式ではない。比率 `A / E` を `r` とすると、

```text
AirSuperiorityPercent = r / (1 + r) × 100
```

となるため、優勢％を高くするほど、さらに1ポイント上げるために必要な追加制空値が大きくなる。

また、このMODで空軍長の特性名として使われている `air_air_superiority_1/2/3` は、地域の制空値を直接増幅していない。実際の効果は次のとおりである。

```text
air_air_superiority_1 → air_escort_efficiency = +2%
air_air_superiority_2 → air_escort_efficiency = +4%
air_air_superiority_3 → air_escort_efficiency = +6%
```

これは爆撃機等に対する敵妨害を護衛機が相殺する「EscortPower」の倍率であり、地域の `A` または `E` へ直接 `×1.02/1.04/1.06` する補正ではない。

## 2. 表示％の機械語上の式

航空地域UIを組み立てる関数は次のとおり。

```text
FUN_1417f4c00（0x1417f4c00）
```

この関数は、

```text
FUN_140be4510（0x140be4510）
```

から、自国から見た次の2つの集計済み値を受け取る。

```text
score[0] = 自軍・友軍側の有効制空値 A
score[1] = 敵対側の有効制空値 E
```

その後の逆コンパイル結果は、簡略化すると次のとおりである。

```cpp
if (A + E < 1) {
    displayed = 0;
} else {
    displayed = (A * 100000) / (A + E);
    displayed = clamp(displayed, 0, 100000);
}
```

したがって、内部値では次の式になる。

```text
Pfixed = floor(A × 100000 / (A + E))
P      = Pfixed / 100000
```

計算途中では整数除算されるため、厳密には `1/100000` 単位で下方向へ丸められる。その後、UIの％表示用フォーマッタへ渡される。

UIの色分けは同じ関数内で次の閾値を使う。

```text
0% ～ 32.999%   : 赤系
33% ～ 65.999% : 黄系
66% ～ 100%    : 緑系
```

色分けの33％・66％は表示色の閾値であり、航空優勢％の数式を曲げる係数ではない。

## 3. なぜ線形に見えないのか

必要な自軍対敵軍の制空値比は、式を逆にすると分かりやすい。

```text
A / E = P / (1 - P)
```

| 目標航空優勢 | 必要な `A / E` | 意味 |
|---:|---:|---|
| 33.33% | 0.5 | 自軍は敵の半分 |
| 50% | 1.0 | 両軍同値 |
| 60% | 1.5 | 自軍は敵の1.5倍 |
| 66.67% | 2.0 | 自軍は敵の2倍 |
| 75% | 3.0 | 自軍は敵の3倍 |
| 80% | 4.0 | 自軍は敵の4倍 |
| 90% | 9.0 | 自軍は敵の9倍 |
| 95% | 19.0 | 自軍は敵の19倍 |

例えば、50％から60％へ上げるには、敵の制空値が固定なら自軍値を1.0倍から1.5倍へ、すなわち50％増やす必要がある。60％から70％へ上げるには、必要比率が1.5倍から約2.333倍へ増える。

この比率式が、「機数または制空値を同じ量だけ足しても、航空優勢％が同じポイント数だけ増えない」主因である。べき乗、平方根、シグモイド等の追加曲線が表示％変換に使われているわけではない。

## 4. 制空値を割合強化した場合

仮に自軍の集計済み制空値だけへ、真に `+B` の倍率が掛かる補正が存在するなら、補正後は次の式になる。

```text
Pnew = A × (1 + B) / (A × (1 + B) + E)
```

元の航空優勢を `P` として書き換えると、

```text
Pnew = P × (1 + B) / (1 + P × B)
```

つまり「制空値+10％」は「航空優勢+10ポイント」ではない。

両軍が補正前に同値、すなわち50％だった場合の理論値は次のとおり。

| 仮想的な自軍制空値補正 | 補正後航空優勢 | 上昇ポイント |
|---:|---:|---:|
| +2% | 50.495% | +0.495pt |
| +4% | 50.980% | +0.980pt |
| +6% | 51.456% | +1.456pt |
| +10% | 52.381% | +2.381pt |
| +20% | 54.545% | +4.545pt |
| +50% | 60.000% | +10.000pt |
| +100% | 66.667% | +16.667pt |

ただし、これは「その補正が本当に `A` へ掛かる場合」の一般式である。次節の空軍長「航空優勢」+5/+10/+15％にも、内部名 `air_air_superiority_*` の+2/+4/+6％にも、この表を適用してはいけない。

## 5. このMODの空軍長「航空優勢」の実作用

### 5.1 公式日本語表示の「航空優勢」は `ground_support`

定義場所は次のとおり。

```text
common/country_leader/00_traits.txt
```

公式日本語版で「航空優勢」と表示される対象は、内部名では `air_chief_ground_support_*` である。実データは次の構造になっている。

```text
air_chief_ground_support_1 = {
    army_bonus_air_superiority_factor = 0.05
}

air_chief_ground_support_2 = {
    army_bonus_air_superiority_factor = 0.10
}

air_chief_ground_support_3 = {
    army_bonus_air_superiority_factor = 0.15
}
```

ファイル内の英語コメントも、次のように作用先を明記している。

```text
Air superiority impact on land units improved by 5/10/15%
```

従って、このmodifierは地域の有効制空値 `A` や航空優勢％を増加させるものではない。地域で成立した航空優勢が陸上戦闘の師団へ与える効果を、+5/+10/+15％強化する。

処理の順序は概念的に次のとおりである。

```text
自軍・敵軍の有効制空値 A, E
  ↓
地域航空優勢率 P = A / (A + E)
  ↓
Pから陸戦への航空優勢効果を計算
  ↓
army_bonus_air_superiority_factor でその陸戦効果を強化
```

つまり「航空優勢+10％」は、地域航空優勢が50％から55％になるという意味ではない。同じ航空機数・同じ有効制空値なら地域表示は50％のままであり、陸戦で航空優勢が師団へ及ぼす効果の側が強くなる。

### 5.2 陸戦ペナルティ、空軍長、師団対空値を接続した実式

実行ファイルの `FUN_140be3880`、`FUN_14125a700`、`FUN_14125ce80` を接続すると、敵航空優勢による陸戦modifierは概略次の順で作られる。

敵側の地域航空優勢率を、

```text
P = E / (A + E)
```

とする。敵側が優勢、すなわち `E > A` の場合だけ、地域航空優勢差が、

```text
ControlTerm = 2 × (P - 0.5) × D
```

へ変換される。`D` は地域データの敵側フィールド `+0x18` に保存された絶対的な航空効果係数であり、単なる陣営間比率とは別に掛かる。従って、同じ75％対25％でも、敵航空戦力の絶対的な存在量が不足する場合には陸戦効果がさらに弱くなる。

空軍長等を含む倍率を、

```text
G = max(0,
        1
        + army_bonus_air_superiority_factor
        + enemy_army_bonus_air_superiority_factor)
```

とすると、師団対空値を入れる前の陸戦ペナルティは、

```text
BasePenalty
  = ENEMY_AIR_SUPERIORITY_IMPACT
  × ControlTerm
  × G
```

となる。このMODでは `ENEMY_AIR_SUPERIORITY_IMPACT = -0.35` である。

師団対空値 `AA` による相殺量は、

```text
X = AA ^ 1.5
AAReduction = a × X / (X + b)
```

である。このMODでは `a = 1.0`、`b = 1000` である。

重要なのは、`AAReduction` が `BasePenalty` へ乗算されるのではなく、正の値として加算されることである。最終的に負値だけが戦闘modifierとして登録される。

```text
FinalPenalty = min(0, BasePenalty + AAReduction)
```

従って、以前想定していた次の式は誤りである。

```text
誤: FinalPenalty = BasePenalty × (1 - AAReduction)
```

`D = 1`、空軍長等なしという最大効果側の仮定で、ペナルティを完全にゼロへ戻すのに必要な師団対空値は次のとおり。

| 敵航空優勢率 `P` | 対空前ペナルティ | 完全相殺AA |
|---:|---:|---:|
| 55％ | -3.5％ | 11.0 |
| 60％ | -7.0％ | 17.8 |
| 66.67％ | -11.67％ | 25.9 |
| 75％ | -17.5％ | 35.6 |
| 80％ | -21.0％ | 41.3 |
| 90％ | -28.0％ | 53.3 |
| 100％ | -35.0％ | 66.2 |

空軍長「航空優勢」+10％まで含めると、必要AAは概ね次のようになる。

| 敵航空優勢率 `P` | +10％後のペナルティ | 完全相殺AA |
|---:|---:|---:|
| 60％ | -7.7％ | 19.1 |
| 75％ | -19.25％ | 38.5 |
| 80％ | -23.1％ | 44.9 |
| 90％ | -30.8％ | 58.3 |
| 100％ | -38.5％ | 73.2 |

`D < 1` なら実際の必要AAはこの表よりさらに低くなる。従って、`AAReduction` の曲線を0～100％まで単独で描いただけのグラフは、師団対空値の設計判断には不十分である。少なくとも `P`、`D`、`G`、そしてゼロでの打ち止めを同時に表示する必要がある。

また、これは敵航空優勢による陸戦modifierだけの評価である。CASから受ける直接ダメージの軽減と航空機撃墜は別処理なので、その目的まで含めた最適AAはこの表だけでは決められない。

### 5.3 内部名 `air_air_superiority_*` は別特性

同じファイルには、非常に紛らわしい別の定義もある。

```text
air_air_superiority_1 = { air_escort_efficiency = 0.02 }
air_air_superiority_2 = { air_escort_efficiency = 0.04 }
air_air_superiority_3 = { air_escort_efficiency = 0.06 }
```

こちらの `air_escort_efficiency` は、概略として次の護衛スコアの最終倍率である。

```text
EscortPower
  = EscortPlaneCount
  × 機体性能・探知等による項
  × ESCORT_FACTOR
  × (1 + air_escort_efficiency)
```

護衛スコアと敵妨害スコアから、

```text
ReductionRatio = min(EscortPower / EnemyDisruption, 1)
EffectiveDisruption = RawDisruption × (1 - ReductionRatio)
```

が作られる。

したがって、こちらの特性は次のように整理できる。

- 地域の制空値 `A` を直接増やさない。
- 航空優勢％の分数式へ直接入らない。
- 護衛側の妨害相殺能力を+2/+4/+6％する。
- 爆撃・攻撃任務が敵戦闘機から受ける妨害を間接的に減らす。
- その結果として作戦成果や、その後の航空戦力残存数へ間接効果が出ることはある。

内部特性名が `air_air_superiority_*` であるため紛らわしいが、公式日本語表示の `ground_support`＝「航空優勢」とは別物であり、こちらも「地域航空優勢％そのものへの+2/+4/+6％」ではない。

## 6. `air_superiority_efficiency` も別物

さらに、次のmodifierも名称が似ている。

```text
air_superiority_efficiency
```

このMODの日本語表示は「制空作戦効率」である。実装上は制空任務中の、

```text
Air Attack
Air Defence
Agility
```

へ同率を加算する任務固有戦闘modifierである。一般的な任務遂行率、参加機数、地域制空値を直接上げない。

従って、似た名称は次の3種類に分ける必要がある。

| 名称 | 実作用 | 地域航空優勢％への直接効果 |
|---|---|---|
| 機体stat `air_superiority` | 1機当たりの制空値 | あり |
| `army_bonus_air_superiority_factor` | 地域航空優勢が陸上師団へ与える効果 | なし |
| `air_superiority_efficiency` | 制空任務中の攻撃・防御・機動性 | なし |
| `air_escort_efficiency` | 護衛による妨害軽減スコア | なし |

## 7. 分子・分母へ入る制空値について

地域UIが割合へ変換する直前の `A` と `E` は、各航空隊の寄与を陣営別に集計した有効制空値である。

航空更新トレーサを作る、

```text
FUN_140b8b4a0（0x140b8b4a0）
```

では各航空隊について、少なくとも次の値を同時に保存している。

```text
航空隊の機数
一般的な任務遂行率
機体設計から得た air_superiority stat（stat ID 0x33）
任務種別・稼働状態
```

したがって、通常の航空隊寄与を理解する基本形は次のとおりである。

```text
WingSuperiorityContribution
  ≈ ActivePlaneCount
  × AirSuperiorityStat
  × GeneralMissionEfficiency
```

複数航空隊・友軍国の寄与を陣営別に合計した後、地域対空砲・SAM等の別処理を反映した集計値が、UIで使われる `A` と `E` になる。

ただし今回、表示％変換は機械語で完全に確定できた一方、すべての任務ビット、空母発進状態、SAM、地域対空砲を含む「集計値生成側」の全分岐はまだ一つの閉じた関数として復元できていない。そのため、この節の積は基本構造として高確度だが、任務ごとの参加条件まで含む完全式とは区別する。

このMODで確認できる周辺defineは次のとおり。

```text
NBuildings.ANTI_AIR_SUPERIORITY_MULT = 5.0
NBuildings.SAM_MISSION_SUPERIORITY   = 5.0
```

また、

```text
NAI.AIR_SUPERIORITY_FACTOR = 2.5
```

も存在するが、これは `NAI` 名前空間にあるAIの地域評価用係数である。プレイヤーの地域航空優勢スコアや表示％を2.5倍するdefineではない。

## 8. 実例

### 8.1 自軍1200、敵軍800

```text
1200 / (1200 + 800) = 0.60
航空優勢 = 60%
```

### 8.2 自軍1000、敵軍800

```text
1000 / (1000 + 800) = 0.55555...
航空優勢 ≒ 55.56%
```

自軍は敵より25％多いが、表示は62.5％ではなく55.56％になる。分母に自軍値も入るためである。

### 8.3 両軍1000で、自軍だけを本当に+10％できた場合

```text
Anew = 1000 × 1.10 = 1100
Pnew = 1100 / (1100 + 1000)
     ≒ 52.38%
```

ただし、このMODの空軍長「航空優勢」特性は `air_escort_efficiency` なので、この例のようには地域％を変化させない。

## 10. 最終整理

```text
地域航空優勢％
  = 自軍有効制空値
    / (自軍有効制空値 + 敵軍有効制空値)
    × 100
```

- 非線形に感じる原因は、分母にも自軍値が入る比率式である。
- 60％には敵の1.5倍、75％には3倍、90％には9倍の制空値が必要。
- 公式日本語表示の空軍長「航空優勢」+5/+10/+15％は `army_bonus_air_superiority_factor` であり、地域％ではなく陸上師団への航空優勢効果を強化する。
- 内部名 `air_air_superiority_*` の+2/+4/+6％は別特性の `air_escort_efficiency` で、護衛による妨害軽減を強化する。
- `air_superiority_efficiency` も地域％ではなく、制空任務中の空戦能力を上げる。
- 地域％へ直接関係する機体側の値は、装備statの `air_superiority` である。
- `NAI.AIR_SUPERIORITY_FACTOR = 2.5` はAI評価用で、表示％の式には入らない。
