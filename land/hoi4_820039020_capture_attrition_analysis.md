# HOI4「innovative balance」鹵獲・消耗 内部計算調査

調査対象：Workshop ID `820039020`、MOD version `13.00`、対応表記 `1.17.5.2`  
対象フォルダ：`C:\Program Files (x86)\Steam\steamapps\workshop\content\394360\820039020`  
調査日：2026-08-22

## 結論

このMODの陸軍装備消耗は、概ね次の式で装備種類ごとに1日1回計算される。

```text
期待損失数
= 現有装備数
  × 総消耗率
  × 0.005
  × 移動係数（停止中 1.0、移動中 1.2）
  × {1 - min(1, 装備信頼性 × (1 + 師団の reliability_factor))}
```

小数部分は切り捨てではなく確率丸めされる。たとえば期待損失が `0.24` なら、24%で1個、76%で0個を失う。`1.20`なら1個は確定し、20%でさらに1個を失う。

鹵獲はこの消耗損失には適用されない。通常の鹵獲対象は「勝利した陸戦で敵が失った装備」の専用プールであり、戦闘終了時に一括処理される。降伏時の装備移管、鉄道砲の捕獲、補給用トラックの消耗も、それぞれ別処理である。

このMODでは、主な基礎値は次のとおり。

| 項目 | MOD値 | 実際の意味 |
|---|---:|---|
| `ATTRITION_EQUIPMENT_LOSS_CHANCE` | 0.005 | 総消耗率と不信頼度に掛かる装備損失係数 |
| `ATTRITION_WHILE_MOVING_FACTOR` | 1.2 | 移動中の**装備損失だけ**を20%増加 |
| `ATTRITION_DAMAGE_ORG` | 0.08 | 総消耗率に掛かる指揮統制率損失 |
| `OUT_OF_SUPPLY_ATTRITION` | 0.20 | 補給切れ由来の最大消耗率 |
| `TRAINING_ATTRITION` | 0.05 | 演習中に加算される消耗率 |
| `UNIT_UPKEEP_ATTRITION` | 0.00 | 常時消耗。このMODではゼロ |
| `EQUIPMENT_COMBAT_LOSS_FACTOR` | 0.70 | 戦闘で受けた充足率損害の70%を装備損失へ換算 |
| `BASE_CAPTURE_EQUIPMENT_RATIO` | 0.00 | 全師団共通の陸戦鹵獲率。MODではゼロ |
| `RELIABILTY_RECOVERY` | 0.10 | 戦闘後の自己装備回収に使う係数（define名は原文どおりの綴り） |
| `CAPITULATE_STOCKPILES_RATIO` | 0.50 | 降伏時の装備移管率 |
| `TRUCK_ATTRITION` | 0.003 | 補給用トラックの基礎消耗 |
| `TRUCK_ATTRITION_FACTOR` | 0.65 | トラック消耗全体の最終スケール |

`00_defines.lua` の1881行付近にも `ATTRITION_WHILE_MOVING_FACTOR` や `ATTRITION_DAMAGE_ORG` という同名項目があるが、そちらは海軍用のdefine節である。陸軍師団の式が参照するのは893行付近の `NMilitary` 側（ORG 0.08、装備損失確率0.005）であり、海軍側のORG 0.01やSTR関連値は混ぜていない。

## 1. 「消耗」「戦闘損失」「回収」「鹵獲」は別物

内部では少なくとも次の経路が分かれている。

| 経路 | 発生タイミング | 信頼性 | 鹵獲対象か | 主な係数 |
|---|---|---|---|---|
| 師団の通常消耗 | 日次更新 | 有効信頼性で軽減 | ならない | `ATTRITION_EQUIPMENT_LOSS_CHANCE` |
| 陸戦の装備損失 | 戦闘損害の確定時 | 通常消耗式とは別 | 敵の勝者側鹵獲プールになる | `EQUIPMENT_COMBAT_LOSS_FACTOR` |
| 戦闘後の自己回収 | 戦闘終了時 | 装備本来の信頼性の二乗 | 自軍へ戻る処理 | `RELIABILTY_RECOVERY`、`recovery` |
| 勝利側の鹵獲 | 勝利した陸戦の終了時 | 鹵獲率には直接入らない | 敵損失から取得 | `BASE_CAPTURE_EQUIPMENT_RATIO`、師団・指揮官・国家補正 |
| 降伏時移管 | 国の降伏処理 | 無関係 | 戦闘鹵獲とは別 | `CAPITULATE_STOCKPILES_RATIO` |
| 鉄道砲捕獲 | 鉄道砲のオーバーラン等 | 無関係 | 専用判定 | `NRailwayGun.BASE_CAPTURE_CHANCE` |
| 補給トラック消耗 | 補給網更新 | 師団装備信頼性とは別 | ならない | `NSupply.TRUCK_ATTRITION` ほか |

したがって、ログの「消耗損失」と「戦闘で失った装備」と「鹵獲した装備」をそのまま同じ式に入れることはできない。

## 2. 内部数値と丸め

陸軍の主要計算は `100000 = 1.0 = 100%` の固定小数点で行われる。乗算の途中で整数除算が入るため、式を実数で書いた結果と完全には一致せず、各段階で最大 `0.00001` 程度の切り捨てが生じる。

装備数は装備種類・派生型ごとに処理される。期待損失の整数部は必ず失われ、小数部だけが `0～99999` の乱数で確率丸めされる。最後に現有数を超えないよう制限される。

## 3. 総消耗率の組み立て

装備損失式に入る総消耗率を `A` とすると、概念的には次の合計になっている。

```text
A_before_modifier
= 常時維持消耗
  移動中の地形消耗
  州・プロヴィンス由来の消耗
  補給不足消耗
  天候の通常 attrition
  寒冷消耗
  暑熱消耗
  演習消耗
  国境紛争消耗

A = A_before_modifier × max(0, 1 + 師団の attrition 補正)
```

### 3.1 常時維持消耗

```text
常時維持消耗
= UNIT_UPKEEP_ATTRITION
   × max(0, 1 + unit_upkeep_attrition_factor)
```

このMODでは `UNIT_UPKEEP_ATTRITION = 0.00` なので、通常はゼロである。

### 3.2 地形消耗

地形消耗は、対象地形で部隊が移動しているときに加算される。MODの地形値は次のとおり。

| 地形 | `attrition` |
|---|---:|
| 山岳 | 0.30 |
| ジャングル | 0.20 |
| 湿地 | 0.35 |
| 砂漠 | 0.15 |

装備派生型が持つ地形別の消耗補正も、保有中の各装備種類について合算される。地形・常時維持消耗との合計が負になる場合は、この部分だけゼロまで戻される。

注意点は、移動係数 `1.2` とは別だということである。移動中は、まず地形消耗が総消耗率へ加わり、その後さらに最終装備損失へ `1.2` が掛かる。山岳を移動することには二段階の不利がある。

### 3.3 天候・気候消耗

天候には三種類の寄与がある。

```text
通常天候消耗 = weather.attrition

寒冷消耗
= max(0,
   weather.winter_attrition
   × 気候影響度
   × (1 + winter_attrition_factor))

暑熱消耗
= max(0,
   weather.heat_attrition
   × 気候影響度
   × (1 + heat_attrition_factor))
```

`気候影響度` には部隊の寒冷・暑熱順応状態が使われる。したがって、同じ極寒でも順応状況によって実効値が変わる。

MODの主な値は、泥濘 `attrition = 0.70`、極寒・酷寒 `winter_attrition = 0.25`、猛暑 `heat_attrition = 0.10`、酷暑 `heat_attrition = 0.20` である。

### 3.4 補給不足消耗

補給率を `S`、消耗開始閾値を `T = 0.35`、補給切れ経過日数を `d`、最大化日数を `D = 30` とする。補正がない基本形は次のとおり。

```text
補給不足度 = max(0, 1 - S / T)
時間係数   = d / D
補給不足消耗 = 0.20 × 補給不足度 × 時間係数
```

実装上は `S/T` を最大1に制限してから `1 - S/T` を取る。このため補給率35%以上では補給不足由来の消耗はゼロである。

補給猶予が残っている間は、実補給率と `残り猶予 / SUPPLY_GRACE` の大きい方が有効補給率として使われる。MOD値は `SUPPLY_GRACE = 120`。コメントは「3日」と書かれているが、値を時間と解釈すると120時間は5日であり、コメントと数値が一致していない。実行処理は数値120を参照する。

さらに、部隊・指揮官・国家の補給切れ関連補正が `1 + 補正` の形で掛かり、負の場合はゼロまで制限される。

例：猶予終了後、補給率17.5%、補給切れ15日なら、

```text
0.20 × (1 - 0.175 / 0.35) × (15 / 30)
= 0.05（総消耗率へ5%を加算）
```

### 3.5 演習と国境紛争

停止して演習中の部隊には `TRAINING_ATTRITION = 0.05` が加算される。国境紛争では、内部の勢力均衡値に `BORDER_WAR_ATTRITION_FACTOR = 0.10` を掛けた値が加算される。

## 4. 装備ごとの通常消耗

装備派生型 `e` について、次の値を置く。

- `N_e`：その派生型の現有数（整数部分）
- `R_e`：派生型自体の信頼性
- `F_rel`：師団の `reliability_factor`
- `A`：前節で求めた総消耗率
- `M`：停止中1.0、移動中1.2
- `K`：`ATTRITION_EQUIPMENT_LOSS_CHANCE = 0.005`

実効信頼性と期待損失は次のとおり。

```text
R_effective = R_e × (1 + F_rel)

ExpectedLoss_e
= N_e × A × K × M
  × {1 - min(1, R_effective)}
```

### 4.1 信頼性の境界

- 実効信頼性は上側だけ100%に制限される。
- 100%以上なら通常消耗による装備損失はゼロ。
- このヘルパー内では下側ゼロへの制限はない。負の信頼性を作ると、不信頼度が100%を超えて損失が増え得る。
- `reliability_factor` は装備本来の信頼性へ乗算される。80%の装備に `+20%` なら、実効信頼性は `80% + 20ポイント = 100%` ではなく、`0.80 × 1.20 = 0.96`、つまり96%である。

### 4.2 数値例

装備1000個、信頼性80%を前提とする。

| 状況 | 総消耗率A | 移動係数 | 期待損失/日 |
|---|---:|---:|---:|
| 演習のみ | 0.05 | 1.0 | 0.05 |
| 補給切れが最大 | 0.20 | 1.0 | 0.20 |
| 泥濘、停止中 | 0.70 | 1.0 | 0.70 |
| 泥濘、移動中 | 0.70 | 1.2 | 0.84 |
| 山岳＋泥濘、移動中 | 1.00 | 1.2 | 1.20 |

最後の条件で `reliability_factor = +20%` があれば実効信頼性は96%となり、期待損失は `0.24` まで下がる。

### 4.3 指揮統制率への損害

装備損失とは別に、日次処理で次が引かれる。

```text
指揮統制率損害 = A × ATTRITION_DAMAGE_ORG
               = A × 0.08
```

ここには移動係数1.2も装備信頼性も掛からない。たとえば総消耗率70%なら、最大指揮統制率に対する5.6%相当が失われる。信頼性を100%以上にして装備損失をゼロにしても、この指揮統制率損害は残る。

## 5. 戦闘装備損失と自己回収

通常消耗とは別に、戦闘損害確定処理では、蓄積した充足率損害を最大充足率で割り、0～100%に制限した後、`EQUIPMENT_COMBAT_LOSS_FACTOR = 0.70` を掛ける。

```text
装備損失率
= clamp(蓄積充足率損害 / 最大充足率, 0, 1)
  × 0.70
```

つまり、兵員・充足率損害と装備損失を1対1にはしておらず、MODでは70%に縮小している。この戦闘損失プールが、勝者側の鹵獲処理の基礎になる。

### 5.1 「死者から戻る」装備

戦闘終了後の自己回収率は、装備本来の信頼性を `R`、師団の平坦な `recovery` を `Rec` とすると次の形である。

```text
RecoveryRate = min(1, R² × 0.10 + Rec)
```

装備種類ごとに失われたプールへ掛け、小数は確率丸めされる。ここで使われる `R` は派生型自体の信頼性であり、通常消耗式のような師団 `reliability_factor` は掛けられていない。

例：信頼性80%なら、基本自己回収率は `0.8² × 0.1 = 0.064`、6.4%。このMODの装甲整備中隊は `recovery = 0.10` を持つため、同条件なら16.4%になる。

複数師団がいる側では、回収対象プールを参加師団数で分配した後、各師団についてこの回収計算が行われる。

## 6. 勝利した陸戦での鹵獲

### 6.1 師団の最終鹵獲率

内部の最終鹵獲率 `C_i` は、概念的に次の二段階で作られる。

```text
C_i
= (共通基礎値
   + 師団編制由来の鹵獲値
   + equipment_capture の加算補正)
  × (1 + equipment_capture_factor の乗算補正)
```

共通基礎値はこのMODでは `BASE_CAPTURE_EQUIPMENT_RATIO = 0.0`。

ここで名称に注意が必要である。同じ `equipment_capture_factor` という文字列でも、整備中隊などの**サブユニット能力欄**にある値は師団の基礎鹵獲能力へ組み込まれる。一方、国家指導者などの**modifier欄**にある `equipment_capture_factor` は最終値を `1 + 値` で増幅する。

実行ファイルでは、加算群を足したあと、乗算群を `1 + 合計` として掛けている。最終値への明示的な0～100%制限は、この能力値生成箇所では確認できなかった。通常の非負設定では問題にならないが、極端なMOD値では100%超や負値を作り得る。

### 6.2 このMODの主な鹵獲源

| 出所 | 値 | 種類 |
|---|---:|---|
| 通常整備中隊 | 0.05 | 師団基礎能力 |
| 整備中隊 II～IV | 各 +0.05 | 通常整備中隊の能力を段階強化 |
| 装甲整備中隊 | 0.10 | 師団基礎能力。さらに `recovery = 0.10` |
| フィンランド長距離哨戒支援 | 0.05 | 師団基礎能力 |
| 指揮官特性 `scavenger` | 0.03 | `equipment_capture` の加算 |
| USAの該当idea | 0.125 | `equipment_capture` の加算 |
| 一部エチオピア国家指導者特性 | 0.25 | `equipment_capture_factor`、全体を1.25倍 |
| 一部陸軍ドクトリン・サブドクトリン | 0.01～0.02 | 対象カテゴリの師団能力を強化 |

通常整備中隊は初期5%。II、III、IVの各技術が同じ中隊へ5%ずつ加えるため、IV到達時は通常整備中隊部分だけで20%になる。

例として、師団基礎20%、`scavenger` 3%、USA idea 12.5%、国家側の乗算補正25%なら、

```text
(0.20 + 0.03 + 0.125) × 1.25
= 0.44375（44.375%）
```

### 6.3 敵損失から取得する処理

鹵獲は戦闘中の各射撃ごとではなく、勝利条件を満たした陸戦の終了処理で行われる。対象は敵側の装備損失プールであり、通常消耗で失われた装備や、平時の演習損失は入らない。

参加師団が1個で鹵獲率 `C` の場合、装備種類ごとの期待鹵獲数は概ね次のとおり。

```text
ExpectedCaptured_e = EnemyCombatLossPool_e × C
```

派生型単位で処理され、整数個を取得する。小数部分は乱数で確率丸めされる。

### 6.4 複数師団時の重み付け

複数の勝利師団がいる場合、内部では各師団について正の参加重み `q_i` と鹵獲率 `C_i` を使う。解析できた実装形は次のとおり。

```text
w_i = q_i × C_i
W   = Σw_i

師団iへ割り当てる装備プール比率
= C_i × w_i / W

戦闘全体の実効鹵獲率
= Σ(C_i × w_i) / W
```

全師団の鹵獲率が同じなら、その値がそのまま戦闘全体の鹵獲率になる。率が異なる場合は、高鹵獲率師団が重み `w_i` にも入るため、単純な師団数平均ではない。

`q_i` は実行ファイル上で師団内部の参加数量コンテナ（師団オブジェクト `+0x4b8`）の各値を合計したもの。シンボルが失われているため正式なゲーム内名称までは断定できないが、単なる「師団数1」ではない。端数装備は `w_i` による重み付き乱数で師団へ配られる。

## 7. 降伏、包囲壊滅、鉄道砲

### 7.1 国の降伏時

国の降伏処理は、陸戦鹵獲率を一切使わない。勝者側の取り分 `p_i` と `CAPITULATE_STOCKPILES_RATIO = 0.50` を使う。

```text
移管数_e,i
= floor(
    min(移管元が実際に持つ数_e,
        対象装備数_e × p_i × 0.50)
  )
```

装備を受領可能かという適格性確認が入り、最後は整数個へ切り捨てられる。処理内では備蓄スナップショットと、配備部隊等から作られた別の対象装備プールが処理される。これは `equipment_capture`、整備中隊、`scavenger`、信頼性とは独立している。

### 7.2 包囲壊滅・解散

`ENCIRCLED_DISBAND_MANPOWER_FACTOR = 0.20` は包囲された部隊を解散した際に戻る**人的資源**の割合で、鹵獲率ではない。`OVERSEAS_LOSE_EQUIPMENT_FACTOR = 0.75` も海外解散時の装備喪失経路であり、通常の日次消耗式とは別である。

### 7.3 鉄道砲

鉄道砲には `NRailwayGun.BASE_CAPTURE_CHANCE = 0.20` という独立した20%の捕獲判定がある。通常師団装備の `BASE_CAPTURE_EQUIPMENT_RATIO` や整備中隊の式とは同一ではない。

## 8. 補給用トラックの消耗

補給網で使うトラックは、師団が保有する車両装備の通常消耗とは別の補給システムで処理される。

各補給経路・地域について、概念的には次のハザードを作る。

```text
局所ハザード
= max(0,
   (TRUCK_ATTRITION + truck_attrition の加算群)
   × (1 + truck_attrition_factor の合計))

経路寄与 = 局所ハザード × その区間の実トラック使用量
```

全経路の寄与を合算した後、乱数判定と `TRUCK_ATTRITION_FACTOR = 0.65` を含む最終スケールを経て、実際のトラック派生型から損失が引かれる。トラックの装甲・HPは敵航空攻撃等による「killed」経路で使われ、ログ上も `trucks lost (attrition)` と `trucks lost (killed)` は分離されている。

MODの天候補正は `1 + 値` なので、たとえば次の倍率になる。

| 状況 | `truck_attrition_factor` | ハザード倍率 |
|---|---:|---:|
| 降雪 | 0.30 | 1.30倍 |
| 吹雪 | 1.00 | 2.00倍 |
| 砂嵐 | 3.00 | 4.00倍 |
| 泥濘 | 5.00 | 6.00倍 |
| 洪水 | 3.00 | 4.00倍 |

泥濘だけなら、基礎ハザード部分は `0.003 × 6 = 0.018`。ここから経路の使用量、全経路合計、乱数、最終係数0.65が処理される。

## 9. よくある誤解

1. **表示消耗率70%なら装備の70%を失う、ではない。**  
   70%はさらに0.005、不信頼度、移動係数、現有数へ掛かる。

2. **信頼性+20%は20ポイント加算ではない。**  
   80%装備なら96%になる。

3. **100%信頼性で消耗の全影響が消えるわけではない。**  
   装備損失はゼロになるが、消耗による指揮統制率損害は残る。

4. **移動中1.2倍は総消耗率表示全体を作り直す係数ではない。**  
   最終的な装備損失計算へ掛かる。指揮統制率損害には掛からない。

5. **消耗で捨てた装備を敵が鹵獲するわけではない。**  
   通常鹵獲は勝利した陸戦の敵戦闘損失プールが対象。

6. **降伏時の50%は整備中隊で増えない。**  
   戦闘鹵獲とは別の固定経路。

7. **`equipment_capture_factor` の意味は置かれた文脈で違う。**  
   サブユニット能力としては師団基礎値、国家modifierとしては `1 + 値` の乗算補正になる。

## 11. 確度と限界

- 数式、define参照、固定小数点、丸め、信頼性の上限、各処理が別経路である点は、逆コンパイルと逆アセンブルの双方で確認したため確度が高い。
- 日次装備消耗の呼出しは師団の日次更新経路に置かれている。ゲーム内で時間を進めた動的トレースまでは今回行っていない。
- 複数師団の鹵獲で使う内部重み `q_i` は、コンテナ内数量の合計までは確認できたが、公開シンボルがないため正式名称は断定していない。
- トラック消耗は経路、地域、天候、使用量、乱数を含むため、陸軍装備の通常消耗のような一行の決定式にはならない。上記は主要なハザード生成と最終スケールを分離して記載した。
- MOD中のコメントは参考データとしてのみ扱い、実行ファイルの処理と食い違う場合は実行処理を優先した。
